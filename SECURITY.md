# Sécurité et clés API

Ce projet utilise une clé personnelle pour interroger l’API N2YO.

- Ne publiez jamais le fichier `id_compte.csv` utilisé localement.
- Ne placez pas de clé réelle dans le dépôt, une capture d’écran ou un rapport d’erreur.
- Si une clé a été publiée, demandez son remplacement au fournisseur : supprimer le dernier fichier ne l’efface pas de l’historique Git.
- Respectez le quota et les conditions d’utilisation de N2YO. N’utilisez pas plusieurs comptes pour contourner une limite.

Le fichier `examples/compte.example.csv` contient seulement une valeur fictive à remplacer localement.

Pour signaler un problème, contactez les auteurs sans inclure de clé ni de donnée sensible dans le message.
